# **App Name**: Deployment Tracker

## Core Features:

- Deployment Record Management: Add, visualize, modify, and delete deployment records through a user-friendly interface.
- Autocomplete Fields: Implement autocompletion for 'Programa' and 'Responsable' fields using auxiliary tables for quick entry and consistency.
- Deployment Overview: Provide a table view with columns for date, program, environment, version, action, responsible, and comment, including filtering, sorting, and search functionalities.
- Version Summary: Display the latest versions for each program in pre-production and production environments, updated automatically with new deployment records.
- Data Administration: Allow modification and deletion of programs and responsibles from a secondary view for data maintenance.
- CSV Export: Add feature to export deployment data to CSV files.

## Style Guidelines:

- Primary color: Light blue (#ADD8E6), evoking a sense of calm and reliability suitable for data management.
- Background color: Very light blue (#F0F8FF), maintaining a clean and unobtrusive backdrop.
- Accent color: Pale Green (#98FF98) for interactive elements and highlights, suggesting efficiency and progress.
- Body and headline font: 'Inter' for a modern, neutral, and readable interface. This sans-serif will support a professional presentation of tabular data.
- Simple, outline-style icons for actions such as edit, delete, and export, aligning with the clean aesthetic.
- Inspired by Notion and Airtable, the layout will feature clean tables with smooth scrolling and a prominent '+ Nuevo despliegue' button.
- Subtle animations for adding and editing records, providing a smooth and responsive user experience.
